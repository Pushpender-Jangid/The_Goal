Assertion – Reason Question

14. Complementary Probability
1 Mark
Assertion (A): If \(E\) is an event such that \(P(E)=\frac{1}{999}\), then \(P(\text{not }E)=0.001\).
Reason (R): \[ P(E)+P(\text{not }E)=1. \]

Set 430/1/1
