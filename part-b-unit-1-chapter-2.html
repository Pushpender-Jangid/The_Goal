Digital Documentation

Chapter 2 — Working with Images

Images are used in documents to present information visually, make documents attractive and improve understanding. LibreOffice Writer provides tools to insert, modify, resize, crop, position and manage images and drawing objects.

✍️ Read • Practise • Revise • Recall
01. Introduction to Images

Why are Images Used?

An image can communicate information quickly and can make a document more attractive and easier to understand.

In Writer, an image can be inserted into a document and then modified according to the requirement of the document.

CBSE Focus: The chapter is not only about inserting an image. You should also know how to modify, resize, crop, delete and position an image and how to work with drawing objects.

Major Image Operations

Operation What it does
Insert Adds an image to the document.
Modify Changes properties or appearance of an image.
Resize Changes the height and width of an image.
Crop Removes unwanted portions of an image.
Delete Removes the selected image from the document.
Position Places the image at the required location in the text/page.
🧠 Quick Recall

Insert → Modify → Resize → Crop → Position → Delete

02. Inserting an Image

Insert Image from a File

An image stored on the computer can be inserted into Writer using the Insert → Image command.

🛠️ PRACTICAL — Insert an Image
  1. Open the Writer document.
  2. Place the cursor at the required location.
  3. Choose Insert → Image.
  4. Select the required image file.
  5. Click Open.
✏️ EXAM POINT

The basic menu path for inserting an image from a file is Insert → Image.

Link vs Embedded Image:

When inserting a graphic, LibreOffice can work with an image as a link to the original file or with a copy embedded in the document. For normal school practical work, pay attention to the image insertion and placement options asked in the task.

03. Selecting & Modifying an Image

Selecting an Image

Click an inserted image to select it. Selection handles appear around the image and allow the object to be modified.

Image Properties

The image properties provide options related to size, position, wrapping, cropping and other image settings.

🛠️ PRACTICAL — Open Image Properties
  1. Select the image.
  2. Right-click the image.
  3. Choose the image/properties option available in the context menu.
  4. Modify the required property.
  5. Apply the changes.
Property Purpose
Position and Size Controls the location and dimensions of the image.
Wrap Controls how text flows around the image.
Image Provides image-related options such as flip/link settings.
Crop Trims or scales the selected graphic.
⭐ EXAM LINE

The Image Properties dialog can be used to control important properties such as position, size, wrap and crop.

04. Resizing an Image

Meaning of Resizing

Resizing means changing the height and width of an image.

The image may be enlarged or reduced depending on the available space and purpose of the document.

🛠️ PRACTICAL — Resize
  1. Select the image.
  2. Drag a suitable resize handle.
  3. Adjust the image according to the document.
  4. Check that the image does not become unnecessarily distorted.

Important Difference:

Resize changes the size of the image.
Crop removes a portion of the image.

Resize = Change size

05. Cropping an Image

What is Cropping?

Cropping means removing unwanted portions of an image while retaining the required portion.

🛠️ PRACTICAL — Crop an Image
  1. Select the image.
  2. Open the image cropping option.
  3. Specify the portions that need to be removed.
  4. Apply the crop.
✏️ EXAM POINT

Cropping is used when only a particular part of an image is required and unwanted portions need to be removed.

🧠 Crop = Cut unwanted area

Cropping does not mean deleting the complete image.

06. Deleting an Image

How to Delete an Image?

If an image is no longer required, it can be removed from the document.

🛠️ PRACTICAL — Delete
  1. Click the image to select it.
  2. Press the Delete key.
⭐ EXAM FOCUS

Always select the image before deleting it. Deleting an image removes that image from the document.

07. Positioning Image in Text

Meaning of Positioning

Positioning determines where an image is placed in relation to the page, paragraph or surrounding text.

Why Positioning Matters?

  • Maintains proper document layout.
  • Prevents the image from disturbing important text.
  • Makes the document easier to read.
  • Helps create a professional page design.

Important Wrap Options

None Text does not wrap around the object in the normal wrapping manner.

09. Anchoring

What is Anchoring?

An anchor defines the reference point to which an object is attached.

When the document is edited, the object behaves in relation to the element to which it is anchored.

Types of Anchoring

Anchor Meaning
To Page The object is associated with the current page.
To Paragraph The object is associated with the current paragraph.
To Character The object is associated with a character/reference point.
As Character The object behaves like a character in the text line.
To Frame The object is associated with a frame.
⚓ Anchor = Reference Point
📄 Page
← ⚓ →
🖼️ Image
🛠️ PRACTICAL — Change Anchor
  1. Select the image/object.
  2. Right-click the object.
  3. Open the Anchor submenu.
  4. Select the required anchor type.
🧠 Easy Question Trick

Wrap = How text moves around it
Anchor = What the object is attached to

10. Drawing Objects

What are Drawing Objects?

Drawing objects are graphical objects that can be created inside a document, such as shapes, lines and other graphical elements.

Uses of Drawing Objects

  • Creating diagrams.
  • Highlighting important information.
  • Showing relationships between ideas.
  • Creating flowcharts and simple illustrations.
  • Improving the visual presentation of a document.

✏️ EXAM POINT

Drawing objects can be created and their properties can be changed according to the requirements of the document.

11. Properties of Drawing Objects

Changing Object Properties

The appearance and behaviour of a drawing object can be modified using its properties.

Property Purpose
Area / Fill Changes the inside/fill appearance of the object.
Line Changes the outline of the object.
Position and Size Changes location and dimensions.
Anchor Controls the object's reference point.
Alignment Controls alignment of selected objects.
Arrange Changes the stacking order of objects.
Rotate / Flip Changes orientation of the object.
🛠️ PRACTICAL — Change Object Properties
  1. Select the drawing object.
  2. Open the relevant properties/options.
  3. Change the required property.
  4. Apply the change and check the result.

12. Resizing & Grouping Drawing Objects

Resizing Drawing Objects

A drawing object can be resized to make it larger or smaller according to the document layout.

Grouping Objects

When several objects need to be treated as a single unit, they can be grouped.

Grouping is useful when a diagram contains multiple shapes that need to be moved or formatted together.

⭐ EXAM DIFFERENCE

Resize → changes object size.
Group → combines selected objects so they can be handled as one group.

13. Arrange, Rotate & Flip

Arrange

Arrange changes the stacking order of overlapping objects.

Option Meaning
Bring to Front Moves the selected object to the top of the stacking order.
Send to Back Moves the selected object to the bottom of the stacking order.
Bring Forward Moves the object one level forward.
Send Backward Moves the object one level backward.

Rotate

Rotation changes the angle or orientation of the selected object.

Flip

Flipping changes the object into a mirror-like orientation, horizontally or vertically.

🧠 Quick Recall

Arrange = Layer order
Rotate = Change angle
Flip = Mirror orientation

14. Image vs Drawing Object
Image Drawing Object
Usually an imported picture/graphic. Created using Writer's drawing tools.
Can be resized and cropped. Can be resized and its shape properties can be changed.
Can be positioned in text. Can be positioned and arranged with other objects.
Can have image-specific properties. Can have line, fill and shape-related properties.
🔥 EXAM FOCUS

Do not confuse an imported image with a drawing object. The chapter covers both.

15. Practical Workflow
🛠️ COMPLETE PRACTICAL FLOW
  1. Open/create the Writer document.
  2. Place the cursor where the image is required.
  3. Use Insert → Image.
  4. Select the image file and insert it.
  5. Select the image and adjust its size.
  6. Set the required wrapping option.
  7. Set the appropriate anchor.
  8. Position the image properly in relation to the text.
  9. Crop unwanted portions if required.
  10. Create drawing objects if required.
  11. Resize and group drawing objects when necessary.
  12. Arrange overlapping objects correctly.

Practical Exam Tip:

If the question says “position the image in the text”, do not stop after inserting the image. You should consider its anchor, wrap and position.
