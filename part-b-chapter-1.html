01. Introduction to Styles

What is the problem with Manual Formatting?

In manual formatting, the user selects different parts of a document such as a page, paragraph or words and applies formatting effects using the formatting toolbar.

If the same formatting is required at many places, the formatting steps have to be repeated for every part of the document.

⚠️ Exam Point

Creating a large report with consistent formatting becomes difficult when manual formatting is used.

Why do we use Styles?

  • To avoid inconsistency in formatting.
  • To reduce time and effort.
  • To apply the same formatting consistently.
  • To save formatting information for future use.
  • To focus more on the content of the document rather than its appearance.

Definition of Style ⭐

A Style is a collection of all formatting information which you want to save and then apply on the document.

Example — Title Style

A Title Style can store formatting information such as:

  • Size: 12
  • Name: Bookman Old Style
  • Weight: Bold
  • Alignment: Left
🧠 Remember:

Once a style is created, it can be applied consistently to different titles. If the title format needs to change, the style can be updated instead of formatting every title separately.

02. Style Categories
⭐ VERY IMPORTANT

LibreOffice Writer provides six Style categories.

Category What it is used for
1. Page Style Used for formatting pages. It defines basic page layout such as:
  • Page size
  • Margins
  • Header and footer placement
  • Footnote
  • Borders
  • Background
A document can have one or many page styles.
2. Paragraph Style Used for paragraph formatting. It includes:
  • Tab stops
  • Text alignment
  • Line spacing
  • Borders
Usually, it also includes Character styling attributes.
3. Character Style Used for a block of letters or words within a paragraph. It can change:
  • Text colour
  • Text size
  • Highlighting
  • Emphasis
It changes part of a paragraph without affecting the other part.
4. Frame Style Frames act as containers that can hold:
  • Text
  • Graphics
  • Lists
Frame Style controls the frame's size, position, border and placement of text around a picture.
5. List Style Used to style lists by:
  • Numbering
  • Bullets
  • Different numeric formats
6. Table Style Used to format tables. It can control:
  • Borders
  • Text/border colours
  • Text alignment
  • Patterns
  • Text colour
🔥 Six Categories — One-Line Revision

Page → Page Layout
Paragraph → Paragraph Formatting
Character → Selected Words/Letters
Frame → Text/Graphics/List Container
List → Bullets & Numbering
Table → Table Formatting

⚠️ Exam Trap

If a page style is not specified, Writer uses its built-in Default page style.

03. Styles and Formatting

LibreOffice Writer provides many options and tools to style or format a document.

The formatting options learned in Class IX can also be applied using the Style menu.

Ways to Access Styles

  1. Use the Style option from the Menu Bar.
  2. Use the Style Drop Down List from the Toolbar.
  3. Use the Sidebar Menu by clicking the Styles icon.
  4. Use the keyboard shortcut F11.
🧠 Access Styles =

Menu Bar + Style Drop Down List + Sidebar + F11

Style Categories in Sidebar

The first six icons at the top of the Styles submenu allow selection of different style categories.

Show Preview

The Show Preview option displays the style along with its name in the list.

Style Filter

At the bottom of the Styles menu there is a drop-down list used to select the filter for the style list.

⭐ Direct Exam Point

The default filter for the style list is Hierarchical.

04. Applying an Existing Style

Writer provides many predefined Styles. To apply an existing style:

  1. Select the text/content to be formatted. The selected content may be characters, words, lines, paragraphs, pages, frames or tables.
  2. Choose the appropriate style category from the top of the Styles bar.
  3. A list of styles for that category appears.
  4. Double-click the desired style to apply it.
✅ Remember the sequence:

Select Content → Select Style Category → Choose Style → Double-click

Applying Heading Style

Predefined Heading Styles can be used as bookmarks for browsing the document.

⭐ Exam Point

Heading Styles allow faster browsing of a document by acting as bookmarks.

05. Applying Page Style

Example — Changing Page Orientation

A Page Style can be applied to change the orientation of a page. The textbook demonstrates changing the orientation from Portrait to Landscape.

Steps

  1. Open the required document.
  2. Insert a blank page at the beginning using Insert → Page Break.
  3. Place the cursor at the beginning of the required page.
  4. Open the Style Menu from the Sidebar.
  5. Select Page Styles.
  6. Double-click Landscape.
⚠️ VERY IMPORTANT

Applying Page Style on a page may affect the entire document.

06. Fill Format

What is Fill Format?

Fill Format is used when the same style needs to be applied at many places scattered throughout a document.

Where can Fill Format be used?

  • Pages
  • Frames
  • Tables
  • Lists
  • Paragraphs
  • Characters

Steps to Use Fill Format

  1. Open the document to be styled.
  2. Open the Styles window.
  3. Select the desired style category.
  4. Select the desired style.
  5. Select the Fill Format button.
  6. Move the mouse pointer to the desired location and click.
  7. Repeat until the style has been applied wherever required.
  8. Click the Fill Format button again or press Esc to quit.
⭐ Direct Question

Which option is useful for applying the same style at many scattered places?
Answer: Fill Format

07. Creating a New / Custom Style

Writer provides predefined styles, but sometimes they may not match the user's requirements.

In such cases, Writer allows the user to create a Custom Style.

Method 1 — From Selection

  1. Select the portion of the document whose appearance needs to be changed.
  2. Format it according to the requirement.
  3. Choose the appropriate style category from the top of the Style menu.
  4. Click the Style Action button.
  5. Select New Style from Selection.
  6. Enter a name for the new style.
  7. Click OK.
🧠 Remember:

Custom Style = user-defined style created according to the required formatting.

— ✦ — ✦ — ✦ —
08. Updating a Style

A user-defined style can be modified whenever required. Instead of creating another style, an existing style can be updated.

Basic Process

  1. Select the portion whose formatting needs to be changed.
  2. Modify its formatting as required.
  3. Open the Style Action options.
  4. Choose Update Selected Style.
⭐ Important

A user-defined style can be updated at any point of time.

⚠️ Remember

The steps used for updating a style are based on the same process used while creating/modifying the style.

— ✦ — ✦ — ✦ —
09. Creating Style using Drag and Drop

A new style can also be created by using the Drag and Drop method.

Steps

  1. Select and format the required portion of the document.
  2. Select the appropriate style category.
  3. Select the style under which the new style needs to be created.
  4. Drag the selected portion of text to the Style Menu.
  5. Enter the name of the new style.
  6. Click OK.
🚨 EXAM TRAP

Drag and Drop method cannot be used to create a Page Style.

10. Load Styles

What is Load Styles?

Load Styles is used to copy styles from an existing template or document.

Once styles are copied, a new document can be created with the same appearance as the old document without extra formatting effort.

Steps to Load Styles from a Template

  1. In the Styles Menu, click Load Styles.
  2. The Load Styles dialog box opens.
  3. Choose the category of the document.
  4. Find and select the desired template.
  5. Select the types of styles to be copied.
  6. Use the Overwrite option if existing styles with the same name need to be replaced.
  7. Click OK.

Types of Styles that can be Loaded

  • Text — Paragraph and Character styles
  • Frame styles
  • Pages styles
  • Numbering / List styles

Loading Styles from a File

  1. Open the Load Styles dialog.
  2. Instead of Template option, click From File.
  3. The File Selection dialog box appears.
  4. Select the desired document from the computer.
⭐ Important Terms

Load Styles → Copy styles from template/document.

Overwrite → Existing styles with the same name are replaced.

From File → Load styles from a selected document file.

11. Applying Styles in a New Document

Whenever a new document is created, Writer applies default style(s) to it.

The current default style is displayed in the Status Bar.

🧠 Exam Memory

New document → Default Style → Displayed in Status Bar

12. ⭐ Most Important Exam Points
  • A Style is a collection of formatting information.
  • Writer provides six Style categories.
  • The six categories are: Page, Paragraph, Character, Frame, List and Table.
  • F11 is used to access Styles.
  • The default Style filter is Hierarchical.
  • Show Preview displays the style along with its name.
  • Heading Styles can act as bookmarks for faster browsing.
  • Fill Format is used to apply the same style at scattered locations.
  • Fill Format can be stopped using Esc.
  • Custom Styles can be created using the Selection method.
  • Custom Styles can also be created using Drag and Drop.
  • Drag and Drop cannot create a Page Style.
  • Existing user-defined styles can be updated.
  • Load Styles copies styles from an existing template or document.
  • Overwrite replaces existing styles having the same name.
  • From File loads styles from a selected document.
  • A new Writer document uses default styles.
