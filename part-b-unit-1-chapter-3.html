Advanced Features of Writer

LibreOffice Writer provides advanced features that help us create, organize, update and review professional documents. This chapter focuses on Table of Contents, Templates and Track Changes.

✍️ Learn • Practise • Revise
01. Table of Contents

What is a Table of Contents?

A Table of Contents (ToC) is a list of the topics and subtopics present in a document along with their corresponding page numbers.

In LibreOffice Writer, a ToC can be created automatically from the headings and subheadings used in the document. The entries can also work as hyperlinks, allowing the user to move directly to a selected topic.

Remember: A Table of Contents is not created by simply typing the topic names manually. It is generated using the document's heading structure.

Why is Table of Contents Useful?

  • Provides an overview of the document.
  • Helps the reader locate a topic quickly.
  • Shows the structure of a long document.
  • Reduces the need to search page by page.
  • Can be updated when headings or page numbers change.
  • Provides navigation through hyperlinks.
✏️ EXAM POINT

The entries of an automatic ToC are taken from the headings and subheadings of the document.

Hierarchy of Headings

A long document is normally divided into different levels of headings. This arrangement is called the hierarchy of headings.

Heading Level Purpose Example
Heading 1 Main topic or chapter Chapter 3: Advanced Features
Heading 2 Major section inside the chapter Table of Contents
Heading 3 Subsection inside a section Creating a Table of Contents
Heading 4+ Further levels of subtopics Customization Options
🧠 Easy Rule

Heading 1 → Main Topic
Heading 2 → Section
Heading 3 → Subsection

02. Creating a Table of Contents

Before Creating a ToC

Before inserting a Table of Contents, the document should have a proper heading structure.

  1. Apply appropriate heading styles to chapter titles.
  2. Use lower-level headings for sections and subsections.
  3. Maintain a logical order of headings.

Steps to Create a Table of Contents

Step 1: Apply heading styles such as Heading 1, Heading 2 and Heading 3 to the document headings.
Step 2: Place the cursor at the location where the Table of Contents is required.
Step 3: Choose Insert → Table of Contents and Index → Table of Contents.
Step 4: Configure the required options in the dialog box.
Step 5: Click OK.
⭐ PRACTICAL EXAM QUESTION

Q. How do you create an automatic Table of Contents?

Ans: Apply heading styles to the document, place the cursor at the desired location, use the Table of Contents command from the Insert menu, configure the options and click OK.

Important Point

If the headings are changed after creating the ToC, the ToC should be updated so that the latest headings and page numbers are displayed.

03. Customizing Table of Contents

Why Customize a ToC?

LibreOffice Writer allows the appearance and structure of a Table of Contents to be changed according to the requirements of the document.

Common Customization Options

Option Purpose
Title Changes the heading/title displayed above the ToC.
Levels Controls how many heading levels appear in the ToC.
Entries Controls the structure and information displayed for each entry.
Styles Controls the formatting of different ToC levels.
Background Allows background formatting for the ToC.

The number of heading levels displayed in the ToC can be controlled according to the required document structure.

Changing ToC Settings

Step 1: Right-click inside the existing Table of Contents.
Step 2: Select Edit Table of Contents.
Step 3: Make the required changes in the dialog box.
Step 4: Click OK to apply the changes.
📌 EXAM DIFFERENCE

Creating ToC → Generates the Table of Contents.

Customizing ToC → Changes its appearance, levels or structure.

Updating ToC → Refreshes entries and page numbers.

— ✦ — ✦ — ✦ —
04. Maintaining a Table of Contents

Updating the Table of Contents

When a document is edited, headings may be added, deleted or moved. Page numbers may also change. Therefore, the Table of Contents should be updated.

Steps to Update ToC

Step 1: Right-click inside the Table of Contents.
Step 2: Select Update Table of Contents.
Step 3: Writer refreshes the entries and page numbers.

Deleting a Table of Contents

Step 1: Right-click inside the Table of Contents.
Step 2: Select Delete Table of Contents.
🧠 ToC Maintenance

Add / Change Heading → Update ToC

No longer required → Delete ToC

✏️ VERY IMPORTANT

If the contents or page numbers of a document change after creating the ToC, the correct action is to update the Table of Contents.

05. Templates

What is a Template?

A template is a pre-designed document that can be used as a starting point for creating new documents.

Templates may contain predefined text, styles, formatting, page layout and other document settings.

Why Use Templates?

  • Saves time while creating documents.
  • Provides a consistent appearance.
  • Reduces repeated formatting work.
  • Helps create professional-looking documents.
  • Can be reused for similar documents.
Template Example Possible Use
Resume template Creating a professional resume.
Report template Preparing repeated reports.
Letter template Creating formal letters with a fixed layout.
Invoice template Preparing documents with a standard structure.

Key Idea: A template is a ready-made starting structure, not merely a blank document.

Using a Template

A template can be used when a user wants to create a new document based on an existing design and formatting.

Basic Workflow

1. Open the Template area in LibreOffice.
2. Select a suitable template.
3. Create a new document from that template.
4. Replace or edit the sample content according to requirements.

Template vs Normal Document

Template Normal Document
Used as a starting structure. Contains the actual document content.
Designed for reuse. Usually created for a particular purpose.
Can contain predefined formatting and styles. Formatting is applied according to the document requirements.
⭐ EXAM POINT

The main advantage of templates is saving time and maintaining consistency in documents.

06. Track Changes

Meaning of Track Changes

The Track Changes feature is used to record and review modifications made to a document.

It is especially useful when more than one person is working on a document and changes need to be reviewed before they become final.

Track Changes can show changes such as insertions, deletions and formatting changes. The changes can later be accepted or rejected.

Why Track Changes is Useful?

  • Records editing made by users.
  • Helps reviewers identify modifications.
  • Allows changes to be accepted or rejected.
  • Useful when documents are reviewed by multiple people.
  • Helps maintain control over document editing.

Recording Changes

Steps

Step 1: Open the document.
Step 2: Go to Edit → Track Changes → Record.
Step 3: Make the required changes in the document.
Step 4: Writer records the modifications.
Step 5: Review the recorded changes.
✏️ EXAM LINE

To start recording changes in Writer: Edit → Track Changes → Record.

— ✦ — ✦ — ✦ —
07. Accepting and Rejecting Changes

Reviewing Changes

After changes have been recorded, the reviewer can examine every modification and decide whether it should remain in the document.

Action Meaning
Accept Change Keeps the selected modification in the document.
Reject Change Removes the selected modification and restores the earlier content.
Accept All Accepts all recorded changes.
Reject All Rejects all recorded changes.

Manage Changes

Step 1: Open Edit → Track Changes → Manage.
Step 2: Review the list of recorded changes.
Step 3: Select a change.
Step 4: Choose Accept or Reject.
🧠 Remember

Accept = Keep the change

Reject = Remove the change

Show / Hide Changes

The display of recorded changes can be shown or hidden without removing the recorded changes themselves.

📌 EXAM TRICK

Show/Hide Changes does NOT mean Accept/Reject Changes.

Showing or hiding only changes their display. Accepting or rejecting actually determines whether the modification remains in the document.

08. Comments and Track Changes

Comments

Comments can be added to a document to provide suggestions, instructions, explanations or remarks without directly changing the main text.

Why Add Comments?

  • To suggest an improvement.
  • To ask another reviewer a question.
  • To explain why a change is required.
  • To provide additional information.

A comment is used for discussion or explanation, while Track Changes records an actual modification made to the document.

Comments Track Changes
Used to add remarks or suggestions. Records modifications made to the document.
Does not itself modify the original text. Records changes such as insertion or deletion.
Useful for communication between reviewers. Useful for reviewing document edits.
⭐ EXAM DIFFERENCE

If the question asks “Which feature records editing?” → Track Changes.

If the question asks “Which feature allows suggestions/remarks?” → Comments.

09. Compare and Merge Documents

Compare Documents

Sometimes a person may edit a copy of a document without turning on Track Changes. LibreOffice Writer can compare the edited document with the original document to identify differences.

Basic Steps to Compare

Step 1: Open the edited document.
Step 2: Select Edit → Track Changes → Compare Document.
Step 3: Select the original document.
Step 4: Writer identifies and marks the differences.
Step 5: Review the detected changes.

Merge Documents

The Merge Document feature is useful when multiple edited copies of the same document have to be combined into the original document.

For merging tracked copies, the documents must have the same original content apart from the recorded changes.

Compare Document Merge Document
Finds differences between two documents. Combines recorded changes from edited copies.
Useful when changes were not tracked. Useful when multiple reviewers have edited copies.
Helps identify modifications. Brings changes into the original document.
✏️ EXAM POINT

Compare = Find differences

Merge = Combine changes

10. Protecting Tracked Changes

Protect Changes

Writer provides an option to protect recorded changes so that a user cannot simply turn off change recording or accept/reject changes without the required password.

Concept

Record Changes: Starts recording modifications.
Protect Changes: Restricts users from disabling or modifying the review process without authorization.
🧠 Easy Recall

Record → Track the edits

Protect → Protect the tracking process

📌 IMPORTANT

Protecting changes is different from accepting or rejecting changes. Protection controls access to the change-tracking process.
