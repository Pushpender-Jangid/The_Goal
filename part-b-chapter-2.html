01. Digital Image

What is a Digital Image?

A picture used in a digital document is called a digital image. It is a representation of an image using a finite set of digital values.

Pixels

A digital image is represented using pixels.

These pixels are stored in different types of graphics files.

Common Image File Extensions

  • GIF
  • JPG
  • JPEG
  • PNG
  • BMP
⭐ EXAM POINT

JPG/JPEG is an image format associated with Joint Photographic Experts Group.

🧠 Remember:

Digital Image → Representation → Pixels → Image File

02. Inserting an Image

LibreOffice Writer allows images, shapes, charts and diagrams to be used in documents.

Methods of Inserting an Image

  • Using Insert Image dialog box
  • Using Drag and Drop
  • Using Cut, Copy and Paste
  • Using Linking
⭐ VERY IMPORTANT

The textbook explains four ways of inserting an image: Insert Image dialog, Drag and Drop, Cut/Copy/Paste and Linking.

Method 1 — Insert Image Dialog Box

  1. Open the document in LibreOffice Writer.
  2. Place the cursor where the image needs to be inserted.
  3. Select Insert → Image from the Menu Bar.
  4. The Insert Image dialog box opens.
  5. Select the required image file.
  6. Click Open.
✅ Shortcut Revision

Insert → Image → Select File → Open

03. Drag and Drop Method

An image can also be inserted by dragging it from the required location and dropping it into the document.

Important Concept

When an image is inserted using the normal insertion methods, a copy of the image is saved inside the document. This is called embedding.

Copy and Paste Method

An image can be copied from another document and pasted into the target document.

  1. Open the source and target documents.
  2. Select the image in the source document.
  3. Use Ctrl + C or the Copy command.
  4. Switch to the target document.
  5. Place the cursor where the image is required.
  6. Use Ctrl + V or Paste.
🧠 Keyboard Shortcuts:

Copy → Ctrl + C
Paste → Ctrl + V

04. Linking an Image

What is Linking?

If the same image needs to be inserted multiple times, it can be useful to save the link/reference of the image instead of saving the image itself inside the document.

Linking stores the reference of an image instead of embedding the actual image.

Advantage of Linking

The actual image is stored separately, so linking can reduce the size of the document when multiple copies of the same image are required.

How to Link an Image?

  1. Open the Insert Image dialog box.
  2. Select the required image.
  3. Enable the Link option.
  4. Insert the image.
⭐ EXAM POINT

Shortcut mentioned in the textbook for linking an image by drag and drop: Ctrl + Shift while dragging and dropping.

Embedding vs Linking

Embedding Linking
A copy of the image is saved inside the document. The reference/link of the image is stored.
Document contains the image itself. Actual image remains as a separate file.
Useful when the image should be stored with the document. Useful when multiple copies of the same image are required.
Generally increases document size compared with linking. Can reduce document size when the same image is used multiple times.

05. Modifying an Image

After inserting an image, it may need to be modified according to the requirement of the document.

Image Toolbar

The Image Toolbar automatically appears when an image is inserted or selected.

It can also be displayed through:

View → Toolbars → Image

Important Image Toolbar Tools

Image Filter

Provides filters for improving or changing the appearance of an image.

Image Mode

Can change the image to: black and white, grayscale or watermark.

Crop

Cuts off the non-desirable part of an image.

Flip Horizontally

Flips the image horizontally by 180°.

Flip Vertically

Flips the image vertically by 180°.

Rotate 90° Left

Rotates the image 90° towards the left.

Rotate 90° Right

Rotates the image 90° towards the right.

Rotate

Allows the image to be rotated through any required angle.

Transparency

Makes an image transparent using a percentage value.

Colour

Allows adjustment of colour components, brightness, contrast and gamma.

Colour Tool Components

Component Purpose
Red Adjusts the red colour component.
Green Adjusts the green colour component.
Blue Adjusts the blue colour component.
Brightness Adjusts brightness.
Contrast Adjusts contrast.
Gamma Adjusts gamma.
⭐ DIRECT EXAM POINT

The Colour drop-down contains six components: Red, Green, Blue, Brightness, Contrast and Gamma.

06. Image Filters

LibreOffice Writer provides 11 types of image filters.

Filter Effect
Invert Inverts colour values. For grayscale images, brightness is inverted.
Smooth Softens the contrast of the image.
Sharpen Increases image contrast.
Remove Noise Removes single pixels from the image.
Solarisation Reverses the tone of a photograph.
Aging Simulates the effect of time on a picture.
Posterise Makes a picture appear like a painting by reducing colours.
Charcoal Sketch Changes the image into a charcoal-sketch style.
Relief Adjusts light source to create a shadow effect.
Mosaic Joins groups of pixels into a single area of one colour.
⭐ EXAM ALERT

Aging → simulates the effect of time.
Posterise → makes picture appear like a painting.
Charcoal Sketch → charcoal sketch effect.
Mosaic → joins groups of pixels.

⚠️ Important

The textbook states that the Image Filter window contains 11 filters. The listed filter table is an important source-based revision point.

07. Rotating an Image

An inserted image can be rotated using the Rotate tool.

Basic Steps

  1. Insert an image.
  2. Select the image.
  3. Click the Rotate tool.
  4. Four rotation handles appear at the corners.
  5. Move the pointer to a corner until the rotate symbol appears.
  6. Drag the rotate symbol in the required direction.
  7. Release the mouse button after obtaining the required rotation.
🧠 Exam Memory

Corner handles → Rotate

08. Cropping an Image

What is Cropping?

Cropping means cutting off the non-desirable part of an image.

Steps to Crop

  1. Select the inserted image.
  2. Click the Crop tool from the Image Toolbar.
  3. The normal sizing handles change into special cropping handles.
  4. Drag an edge towards the centre of the image.
  5. The unwanted part is cropped.
  6. Click elsewhere on the page or press Esc to leave the crop tool.
⭐ Cropping vs Resizing

Resizing changes the size of the image.

Cropping cuts off a part of the image.

09. Resizing an Image

Meaning

Resizing is the process of reducing or enlarging the size of an image.

Steps

  1. Select the image.
  2. Observe the eight sizing handles.
  3. Place the pointer over a sizing handle.
  4. Click and drag the handle.
  5. Release the mouse button after obtaining the required size.

Corner vs Edge Handles

Handle Effect
Corner handles Change width and height simultaneously.
Other four handles Resize one dimension at a time.
⭐ VERY IMPORTANT

Resizing changes the image's size, while cropping cuts the image.

10. Deleting an Image

An image can be deleted just like text.

  1. Select the image.
  2. Press the Delete key.
🧠 One-Line Answer:

Select Image → Press Delete

11. Drawing Objects

LibreOffice Writer provides Drawing Tools for creating objects such as:

  • Flowcharts
  • Callout boxes
  • Designs
  • Diagrams
  • Other drawings

Drawing objects can be created directly in Writer and can also be copied or imported into other packages.

Displaying Drawing Toolbar

View → Toolbars → Drawing

Basic Steps to Create a Drawing Object

  1. Place the cursor where the drawing should be placed.
  2. Select the required tool from the Drawing Toolbar.
  3. Move the pointer to the desired location.
  4. Click and drag to create the drawing object.
  5. Release the mouse button to finish.
  6. Press Esc or click the Select icon to cancel the selected drawing function.
— ✦ — ✦ — ✦ —

13. Object Properties

Properties of a drawing object can be changed according to the requirement.

Examples of Properties

  • Fill colour
  • Line colour
  • Line width
  • Size
  • Shape
  • Position

Default Values

If properties are modified before creating an object, those settings become the default values for subsequently created objects.

Changing Properties After Creation

Properties can also be changed after the object has already been created.

🧠 Remember:

Before creation → Default values
After creation → Modify selected object

14. Resizing Drawing Objects

Steps

  1. Select the object.
  2. Eight handles appear around the object.
  3. Click and drag one of the handles.
  4. Release the mouse button at the required size.

Maintaining Original Shape

Use the corner handles to resize while maintaining the original shape.

Non-Proportional Resizing

Using edge handles can resize the object non-proportionally.

⭐ EXAM POINT

Corner handle → maintains original shape.
Edge handle → non-proportional resizing.

15. Grouping Drawing Objects

Why Group Objects?

When several shapes are placed together, they may look like one drawing but are actually separate objects.

Grouping allows them to behave as a single entity.

Advantages of Grouping

  • Objects can be handled as one unit.
  • Size and position can be maintained together.
  • A change applied to the group can affect its members.

Steps to Group

  1. Select the first object.
  2. Hold the Shift key.
  3. Select the other objects to be included.
  4. Choose the Group option from Drawing Object Properties Toolbar.

Group Options

Group

Combines selected objects into one group.

Ungroup

Separates grouped objects.

Enter Group

Allows work inside a group.

Exit Group

Leaves the selected group.

⭐ DIRECT EXAM QUESTION

Grouping options are: Group, Ungroup, Enter Group and Exit Group.

16. Positioning an Image

After creating, formatting, resizing and grouping an image or drawing object, it needs to be positioned properly in relation to text and other objects.

Positioning of an image is controlled by FOUR SETTINGS :

  1. Arrangement
  2. Anchoring
  3. Alignment
  4. Text Wrapping

These settings can be accessed through:

  • Format Menu
  • Context Menu after right-clicking
  • Drawing Object Properties Toolbar
17. Arrangement

When objects overlap, arrangement determines the position of the current object with respect to other objects or text.

Tool Effect
Bring to Front Places the image on top of all objects/images.
Forward One Moves the image one level upward.
Back One Moves the image one level downward.
Send to Back Places the image at the bottom of all objects/images.
To Foreground Moves the drawing object in front of the text.
To Background Moves the drawing object behind the text.
⭐ EXAM TRAP

The first four arrangement settings can be applied to images or drawings.

To Foreground and To Background are available for drawings only.

18. Anchoring

What is Anchoring?

Anchor acts as a reference point for an image or drawing.

Anchoring allows an image to retain its position relative to:

  • Page
  • Paragraph
  • Character
  • Frame

When the corresponding page, paragraph, character or frame is moved/aligned, the anchored image moves along with it.

⭐ ONE-LINE ANSWER

Anchor = Reference point for an image/drawing.

19. Alignment

Alignment controls the vertical or horizontal placement of an image with respect to its anchor.

An image can be aligned in six different styles:
3 horizontal + 3 vertical.

🧠 Exam Memory:

Alignment → Position of image relative to its Anchor

20. Text Wrapping

Meaning

Text wrapping controls the placement of an image in relation to surrounding text.

Six Text Wrapping Options

Option Effect
Wrap off Text is placed above and below the image.
Page Wrap Text flows around the image. Moving the image rearranges the text on the page.
Optimal Page Wrap In Page Wrap, if the space between image and margin is less than 2 cm, text is not placed on that side.
Wrap left Text is placed on the left side of the image.
Wrap right Text is placed on the right side of the image.
Wrap through The image is superimposed on the text.
⭐ EXAM POINT

Wrap off → Text above and below.
Page Wrap → Text flows around image.
Wrap left → Text on left.
Wrap right → Text on right.
Wrap through → Image superimposes text.
