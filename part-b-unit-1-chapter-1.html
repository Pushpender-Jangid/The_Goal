Chapter 1 — Introduction to Styles

Styles in LibreOffice Writer help us format a document consistently and efficiently. Instead of formatting every heading, paragraph or page separately, we can create and apply styles whenever required.

✍️ Read • Revise • Recall
01. Introduction to Styles

What is a Style?

A Style is a collection of formatting information that can be saved and applied to different parts of a document.

In LibreOffice Writer, a style can contain several formatting properties such as font, font size, font colour, alignment, spacing, indentation and other formatting settings.

Example:

Suppose all chapter headings in a document should have Bookman Old Style, size 18, bold and left aligned. Instead of applying these settings separately to every heading, we can save them as a style such as "Heading Style".

Manual Formatting vs Styles

There are two common ways of formatting a document in Writer: manual formatting and using styles.

Manual Formatting Using Styles
Formatting is applied directly to selected text or paragraphs. Formatting properties are saved together as a reusable style.
The same formatting may need to be repeated again and again. The same style can be applied wherever required.
Changing a large document can take more time. Major formatting changes become easier.
Consistency can become difficult to maintain. Helps maintain consistent formatting throughout the document.
🧠 Remember:

Style = Saved collection of formatting information

02. Advantages of Using Styles

Why are Styles Useful?

Styles are especially useful when working with long or well-structured documents.

  • They provide consistent formatting throughout the document.
  • They reduce the time and effort required for formatting.
  • A single style can be applied to many parts of the document.
  • Major formatting changes can be made more easily.
  • Styles help organise the structure of a document.
  • Heading styles can help in creating a Table of Contents.
  • They allow the user to focus more on the content rather than formatting every individual part.
✏️ EXAM POINT

The most important advantages of styles are consistency, time saving and easy modification of document formatting.

Key idea:

When the same formatting has to be used repeatedly, using a style is usually more efficient than formatting each item manually.

03. Styles and Formatting Window

What is Styles and Formatting?

The Styles and Formatting area in LibreOffice Writer is used to manage the styles available in the document.

It allows the user to view, apply, create, modify and manage styles.

Opening the Styles Interface

The Styles interface can be opened in different ways.

  1. Use the Styles option from the menu.
  2. Use the Styles icon in the Sidebar.
  3. Use the keyboard shortcut F11.
🧠 Shortcut to Remember:

F11 → Styles

What can we do using Styles?

  • View available styles.
  • Apply a style.
  • Create a new style.
  • Modify an existing style.
  • Update a style.
  • Manage different categories of styles.
— ✦ — ✦ — ✦ —
04. Categories of Styles

Six Important Style Categories

LibreOffice Writer provides different categories of styles. For Class 10 IT, the important categories are:

Style Category Used For
Page Style Controls page-level formatting such as page size, margins, orientation, headers, footers, borders and background.
Paragraph Style Controls formatting of paragraphs such as alignment, line spacing, indentation, spacing and related settings.
Character Style Controls formatting of selected characters or portions of text such as font, size, colour, bold and italic.
Frame Style Used for formatting frames containing text, graphics or other objects.
List Style Controls formatting of numbered and bulleted lists.
Table Style Controls formatting of tables, including borders, backgrounds, alignment and related table formatting.
🧠 Six Categories — Must Remember

Page • Paragraph • Character • Frame • List • Table

⭐ VERY IMPORTANT FOR MCQs

If a question asks which style categories are available in Writer, remember that all six categories are important: Page, Paragraph, Character, Frame, List and Table.

05. Page Style

Meaning

A Page Style controls the layout and appearance of a page.

Important Page Style Properties

  • Page size
  • Page orientation
  • Margins
  • Headers
  • Footers
  • Borders
  • Background

Example:

If a document needs landscape orientation and specific page margins, these settings can be managed through the Page Style.

✏️ EXAM LINE

Page Style → Page Layout

06. Paragraph Style

Meaning

A Paragraph Style controls the formatting and appearance of a complete paragraph.

Important Properties

  • Text alignment
  • Line spacing
  • Indentation
  • Spacing
  • Tab stops
  • Borders and related paragraph formatting
🧠 Remember:

Paragraph Style → Paragraph Formatting

07. Character Style

Meaning

A Character Style is used for formatting selected characters or a portion of text inside a paragraph.

Examples of Character Formatting

  • Font type
  • Font size
  • Bold
  • Italic
  • Underline
  • Text colour
✏️ EXAM DIFFERENCE

Paragraph Style → complete paragraph

Character Style → selected characters/text

08. Frame, List and Table Styles

Frame Style

Frame Styles are used to format frames that may contain text, graphics or other objects.

List Style

List Styles are used for controlling the appearance and formatting of bulleted and numbered lists.

Table Style

Table Styles are used to manage formatting related to tables. They can control features such as borders, background, alignment and other table formatting.

Style Quick Meaning
Frame Frames and objects
List Bullets and numbering

09. Applying Styles

How to Apply a Style?

An existing style can be applied to the required part of a document.

  1. Select the text or place the cursor in the required paragraph.
  2. Open the Styles interface.
  3. Select the required style category.
  4. Choose the desired style.
  5. The selected content gets the formatting defined by that style.

Important:

Applying a style does not mean manually setting every formatting property again. The properties already stored in the style are applied together.

⭐ EXAM FOCUS

Styles are useful because one saved formatting scheme can be applied repeatedly to different parts of a document.

10. Fill Format Mode

What is Fill Format?

The Fill Format feature allows a selected style to be applied quickly to multiple areas of a document.

Basic Steps

  1. Open the Styles interface.
  2. Select the required style.
  3. Activate the Fill Format mode.
  4. Click or select the areas where the style needs to be applied.
  5. Repeat for the required areas.
  6. Turn off Fill Format mode after completing the task.
🧠 Easy Meaning:

Fill Format = Apply the same style quickly at multiple places.

✏️ PRACTICAL QUESTION

If the same style has to be applied to many different areas of a document, Fill Format can save time.

11. Creating a New Style

Why Create a New Style?

Sometimes the existing styles do not provide the exact formatting required. In such a situation, a custom style can be created.

Method 1 — From Selection

A new style can be created from text that has already been formatted according to the required design.

  1. Format a piece of text according to your requirement.
  2. Select the formatted text.
  3. Open the Styles interface.
  4. Choose the option to create a new style from the selection.
  5. Give the new style a suitable name.
  6. Save the style.

Example:

Suppose you create a special format for important definitions. Instead of recreating that format every time, save it as a style and reuse it.

Method 2 — Drag and Drop

Another way to create a new style is by using the drag-and-drop method.

  1. Format the text according to your requirement.
  2. Select the formatted text.
  3. Drag the selected text into the Styles list/panel.
  4. A new style can be created from that formatting.
🧠 Two Creation Methods

From Selection + Drag and Drop

12. Updating a Style

Meaning of Updating a Style

A style can be updated when its formatting needs to be changed according to a new requirement.

For example, if the font or colour of a particular style needs to change, the style can be updated rather than manually changing each occurrence.

Why is Updating Useful?

  • It saves time.
  • It maintains consistency.
  • Changes to the style can affect the content using that style.
  • It avoids repeated manual formatting.

Remember:

If many headings use the same style and that style is updated, the formatting can be changed consistently instead of editing each heading separately.

⭐ EXAM POINT

Updating a style is useful for making consistent formatting changes throughout a document.

13. Loading Styles

Loading a Style from a Template or Document

Writer allows styles to be loaded from an existing template or another document.

This is useful when a particular formatting scheme has already been created and needs to be reused in another document.

Why Load Styles?

  • Avoid creating the same styles repeatedly.
  • Reuse an existing formatting design.
  • Maintain consistency between related documents.
  • Save time while preparing documents.
🧠 Remember:

Existing document/template → Load Styles → Reuse formatting
