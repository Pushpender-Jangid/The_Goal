SESSION 01

Basic Computer Operations

EXAM IMPORTANT

What is ICT?

ICT stands for Information and Communication Technology.

ICT refers to the methods, tools and concepts used for storing, recording and sending digital information.

★ ICT Devices:
Smartphones • Tablets • Laptops • Desktop Computers

Hardware and Software

Hardware Software
Physical parts of a computer that can be seen and touched.

Examples: Keyboard, monitor, CPU. 		Programs that make the hardware work and perform particular functions.

Examples: Operating system, browser, games and office applications.
★ Remember:
Hardware = physical parts
Software = programs/instructions

Operating System (OS)

An Operating System is the most important software in a computer. It starts working when the computer is switched on and provides the environment through which the user can operate the computer.

Examples mentioned in the textbook include Ubuntu, Microsoft Windows and Mac OS for computers and Apple iOS and Google Android for mobile devices.

Starting a Computer

When a computer is switched on, it performs basic processes before it is ready to accept instructions from the user.

Starting sequence:

Power ON → POST/BIOS check → Operating System starts → Login/Welcome screen → Desktop

BIOS

BIOS stands for Basic Input/Output System.

BIOS runs automatically when the computer is switched on. It performs a self-test and, if the system is fine, loads the Operating System.

Login and Logout

A login ID and password help identify an authorised user and restrict unauthorised access.

After finishing work, the user should log out/sign out so that another person cannot access the user's work.

Shutting Down

A computer should be shut down using the operating system's Shut Down option. The operating system closes applications before turning the computer off.

Keyboard

A keyboard is an input device used to enter text, numbers and commands into a computer.

Key / Group Function
Function Keys F1–F12 Perform specific functions depending on the program.
Enter Confirms an instruction or moves to a new line while typing.
Spacebar Inserts a space between words.
Backspace Deletes the character to the left of the cursor.
Arrow Keys Move the cursor in different directions.

Mouse Functions

Function Meaning
Click Press and release the mouse button.
Double-click Click twice quickly.
Right-click Opens a context menu.
Drag and Drop Press and hold the mouse button, move the item and release it.
Hover Move the pointer over an item without clicking.

Quick Recall

ICT → Hardware + Software → OS → BIOS → Login → Work → Logout

SESSION 02

Performing Basic File Operations

VERY IMPORTANT

What is a File?

A file is a collection of information stored electronically on a computer.

Different types of files store different types of information.

What is a Folder?

A folder is a location where a group of files can be stored.

Easy example:
School cupboard → Folder
Student file → Computer file

File Name and Extension

A file has a name and a file-name extension. The extension identifies the type of file and is separated from the file name by a dot.

Extension Common File Type
.txt Text file
.doc Document file
.xls Spreadsheet file
.jpg Image file
.mp3 Sound/audio file

Basic File Operations

  • Create — make a new file or folder.
  • Save — store the file.
  • Copy — make another copy of the file.
  • Move — change the location of a file.
  • Rename — change the name of a file or folder.
  • Delete — remove a file or folder.

Important Keyboard Shortcuts

Ctrl + Z → Undo

Ctrl + Y → Redo

Ctrl + A → Select All

Ctrl + X → Cut

Ctrl + C → Copy

Ctrl + V → Paste

Ctrl + P → Print

Ctrl + S → Save

★ MCQ Favourite:

Ctrl + C = Copy
Ctrl + X = Cut
Ctrl + V = Paste
Ctrl + S = Save
Ctrl + Z = Undo
Ctrl + Y = Redo

Creating a Text File

  1. Open a text editor.
  2. Type the required information.
  3. Choose the Save option.
  4. Select the location where the file should be stored.
  5. Enter the file name.
  6. Save the file.

Creating a Folder

  1. Open the file explorer.
  2. Choose the location where the folder is required.
  3. Right-click and choose New Folder.
  4. Enter the folder name.

Quick Recall

File = Information
Folder = Collection of files
Extension = Identifies file type

SESSION 03

Computer Care and Maintenance

EXAM IMPORTANT

Importance of Computer Care

Regular care and maintenance helps computers and mobile devices work properly for a longer time and helps prevent unnecessary damage and expenses.

Keeping a Device Clean

Part Care
Keyboard Avoid eating over it. Remove dust and crumbs carefully.
Screen Wipe fingerprints and dust using a soft cloth.
Food & Drinks Keep liquids away from electronic devices.
Laptop/Mobile Handle carefully and protect from falls and hard impacts.

Keep the Computer Cool

  • Make sure the CPU fan is working properly.
  • Do not cover laptop ventilation areas.
  • Avoid using devices in direct sunlight for long periods.
  • Do not leave a device inside a closed hot car.
  • Do not block the laptop fan while using it.
★ Important:
Overheating can damage the internal parts of a computer.

Battery Care

Avoid keeping a device plugged in for a long time after it is fully charged because excessive charging can cause the battery to overheat.

Backup Data

Backup means making a copy of important data on another storage location so that the data can be recovered if the original computer or storage fails.

Why backup?
Computers can crash, people can make mistakes and natural disasters can damage equipment. A backup helps recover important data.

Scanning and Cleaning Viruses

Anti-virus software can scan a computer for viruses, help prevent infections and clean viruses that have entered the system.

Improving Computer Performance

Unnecessary files such as temporary files and unused data can occupy hard-disk space. Removing unnecessary files can help maintain computer performance.

SPAM

SPAM refers to unwanted emails, often sent for advertising or attracting users to websites.

  • Do not respond to suspicious spam.
  • Delete unwanted spam.
  • Use spam filters where available.

Quick Recall

Clean → Cool → Handle Carefully → Battery Care → Backup → Anti-virus → Remove Unnecessary Files → Control Spam

SESSION 04

Computer Security and Privacy

HIGH PRIORITY

Why is Computer Security Important?

Computers and electronic devices store important information, including personal, educational, financial and other sensitive data.

Computer security and privacy involve measures used to protect computers and restrict unauthorised access to personal data.

Security Breach

A security breach is the leakage or unauthorised access of information stored on a computer.

Threats to Computer Security

Threat Meaning
Physical Theft Stealing the physical computer or device.
Identity Theft Stealing personal information and using it to assume another person's identity.
Software Piracy Using or distributing unauthorised or unlicensed copies of software.
Virus A harmful computer program that can damage data/software or steal information.
Online Predator A person who may attempt to trap or manipulate others through inappropriate online interactions.
Internet Scam A deceptive online scheme designed to obtain money or personal/account information.

How Personal Information Can Be Lost or Leaked

  • Sharing account details or passwords on unsafe websites.
  • Allowing unauthorised people to access the computer.
  • Leaving a computer without logging out.

Computer Viruses

A computer virus is a harmful program that may damage data or software and may steal information.

Type Meaning
Worm A type of malicious program that can replicate itself and spread to other files or systems.
Trojan Horse A malicious program that disguises itself as useful or legitimate software.

Protecting Your Data

Protection Method Purpose
Strong Password Helps prevent unauthorised access. A strong password can combine letters, numbers and special characters.
Anti-virus Detects, prevents and helps remove viruses.
Firewall Monitors data entering and leaving a computer and helps block harmful or unauthorised access.
Encryption Converts data into a protected form that requires a key/password for authorised access.
Secure Websites Sensitive information such as banking details should only be entered on trustworthy secure sites.
Logout Prevents another person from accessing an account or computer after you finish your work.
★ Exam Favourite:

Password → Prevent unauthorised access
Anti-virus → Detect/remove viruses
Firewall → Controls incoming/outgoing network data
Encryption → Protects data by converting it into a coded form

Safe Internet Habits

  • Do not share passwords with others.
  • Do not enter personal or banking information on suspicious sites.
  • Log out after using a shared computer.
  • Be careful with attractive online offers and unknown messages.
  • Keep security software updated.
  • Keep important data backed up.

Quick Recall

Security → Threats → Virus → Password → Anti-virus → Firewall → Encryption → Secure Sites
