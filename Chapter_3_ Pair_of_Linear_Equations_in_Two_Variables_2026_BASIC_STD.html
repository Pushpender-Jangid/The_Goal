SECTION B : ASSERTION–REASON QUESTIONS (1 Mark Each)
7.
Assertion (A): The value of p for which the system of equations 4x + py + 8 = 0 and 2x + 2y + 2 = 0 is consistent is 4.
Reason (R): The system of equations a₁x + b₁y = c₁ and a₂x + b₂y = c₂ is consistent with infinitely many solutions if a₁/a₂ = b₁/b₂ = c₁/c₂ .
[Sets: 430/1/1, 430/1/2, 430/1/3]

(B) a₁/a₂ ≠ b₁/b₂ = c₁/c₂
