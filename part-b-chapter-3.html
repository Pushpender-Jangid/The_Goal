01. Table of Contents — ToC

What is a Table of Contents?

A Table of Contents (ToC) contains a list of topics and subtopics covered in a document along with their page numbers.

In LibreOffice Writer, ToC can be inserted automatically. The entries are taken from the headings and sub-headings of the document.

Important: The entries in the Table of Contents are hyperlinked. Therefore, clicking the required entry allows navigation directly to that section.

⭐ EXAM POINT

ToC = Topics + Subtopics + Page Numbers + Hyperlinked Entries

02. Hierarchy of Headings

Before creating a Table of Contents, proper heading styles must be applied to the headings and sub-headings.

Heading Levels

LibreOffice Writer supports up to 10 levels of headings: H1 to H10.

Meaning of Heading Hierarchy

Level Meaning
Heading 1 Main / highest-level heading
Heading 2 Sub-heading under Heading 1
Heading 3 Sub-heading under Heading 2
Heading 4–10 Further levels of hierarchy

Applying Heading Styles

  1. Open/create the document.
  2. Open the Styles option from the right sidebar.
  3. Select Paragraph Styles.
  4. Select Headings.
  5. Choose the required Heading 1 to Heading 10 style.
  6. Repeat the process for other headings.
🧠 Remember:

Correct ToC depends on the correct hierarchy of heading styles.

03. Creating a Table of Contents

Requirement Before Creating ToC

Proper paragraph styles such as Heading 1, Heading 2, Heading 3 and so on must already be applied.

Steps to Insert ToC

  1. Open the document.
  2. Apply proper heading styles to all headings and sub-headings.
  3. Place the cursor at the position where the ToC is required. Usually, it is placed at the beginning of the document.
  4. Select:
    Insert → Table of Contents and Index → Table of Contents, Index or Bibliography
  5. The Table of Contents, Index and Bibliography dialog box appears.
  6. The Type tab is selected by default.
  7. Enter/change the title of the ToC if required.
  8. Click OK.

Important Default Options

  • Protected Against Manual Changes checkbox is selected by default.
  • The ToC is generated from the headings and sub-headings of the entire document.
  • The Outline checkbox is selected by default.
  • Headings appear with their page numbers.
  • ToC entries are hyperlinked.
⭐ VERY IMPORTANT

Insert → Table of Contents and Index → Table of Contents, Index or Bibliography is the important menu path for creating a ToC.

🧠 Hyperlink Shortcut:

Ctrl + Click on a ToC entry → directly opens the selected heading.

04. Customisation of ToC

After inserting a ToC, it can be customised according to the document requirement.

Opening Customisation Options

  1. Right-click anywhere on the ToC.
  2. Select Edit Index.
  3. The Table of Contents, Index or Bibliography dialog box opens.

Five Important Tabs

Tab Purpose
Type General type/title and other ToC settings.
Entries Sets styles for different entries in the ToC.
Styles Applies desired styles to the text of each ToC level.
Columns Sets the number of columns in the ToC.
Background Changes the background of the ToC.
⭐ DIRECT EXAM MEMORY

Type → Entries → Styles → Columns → Background

05. Type Tab

The Type tab is active by default when the Table of Contents, Index or Bibliography dialog box is opened for inserting the ToC.

Important Point

The Protected Against Manual Changes checkbox is selected by default.

It protects the ToC from accidental manual changes.

If the checkbox is unchecked, the ToC contents can be changed directly on the document page like normal text.

06. Entries Tab

The Entries tab contains options to set styles for various entries in the ToC.

⭐ EXAM POINT

Entries Tab → Styles for various ToC entries

07. Styles Tab

The Styles tab contains options to apply the desired styles to the text of each level in the ToC.

Applying a Custom Paragraph Style

  1. Select the required level from the Levels list box.
  2. Select the required paragraph style from the Paragraph Styles list box.
  3. Click OK to apply the selected paragraph style.
  4. The assigned style appears in square brackets in the Levels list and is visible in the Preview pane.

Removing Applied Paragraph Style

Select the required level and click the Default button.

08. Columns and Background Tabs

Columns Tab

The Columns tab contains options to set the number of columns in the ToC.

Background Tab

The Background tab contains options to change the background of the ToC.

🧠 Quick Recall:

Columns → Number of columns
Background → Background appearance

09. Updating a Table of Contents

If a document is edited after inserting the ToC, the ToC can be updated to reflect the changes.

Steps to Update ToC

  1. Right-click anywhere in the ToC.
  2. Select Update Index.
  3. The changes are reflected in the ToC.
⭐ ONE-LINE EXAM ANSWER

Update ToC → Right-click ToC → Update Index

10. Deleting a Table of Contents

Steps

  1. Right-click anywhere on the ToC.
  2. Select Delete Index.
🧠 Remember:

Update → Update Index
Delete → Delete Index

11. Templates

What is a Template?

A template is a preset layout that helps create professional and/or formal documents easily.

Why Use Templates?

Templates are useful when the same content, formatting and appearance are required in multiple documents.

A template can contain:

  • Text
  • Graphics
  • Styles
  • Defined headings
  • Text formats
  • Page numbers
  • Headers
  • Footers

Examples

  • Resume
  • Chapter
  • Project Report
⭐ EXAM POINT

Templates save time and effort because the same formatting and content structure can be reused.

12. Default Template

All documents in Writer are based upon templates.

If no specific template is specified, Writer uses the default template for creating a blank document.

Default Template → Blank Document Template

13. Checking the Template of a Document

Steps

  1. Open the document.
  2. Select Properties from the File menu.
  3. The Properties dialog box appears.
  4. The associated template name is displayed there if the document was created using a template.
⭐ EXAM MEMORY

Check associated template → File → Properties

14. Creating and Saving a Template

Steps

  1. Open/create the document whose template is to be created.
  2. Select: File → Templates → Save
  3. The Save As Template dialog box appears.
  4. Enter the name of the new template.
  5. Select the category.
  6. If required, select the Set as default template checkbox.
  7. Click Save.

Writer templates are saved with the extension .ott

⭐ VERY IMPORTANT

.ott → Template file extension

15. Using In-built / Saved Templates

Opening Templates Dialog Box

Keyboard Shortcut:

Ctrl + Shift + N

Steps to Use a Saved Template

  1. Open the Templates dialog box.
  2. Select the desired template.
  3. Click Open.
  4. A new document opens with the same content, appearance and formatting effects as the template.
  5. Make the required changes and save the document.
⭐ EXAM POINT

File → Templates → Manage Templates can be used to access the Templates dialog box.

16. Using Online Templates

LibreOffice provides a wide range of online templates that can be downloaded from the Internet.

Basic Procedure

  1. Open the Templates dialog box.
  2. Click Browse Online Templates.
  3. The online templates page opens in a browser.
  4. Select the required template.
  5. Download the template.
🧠 Exam Keyword:

Browse Online Templates

17. Importing a Template

Steps

  1. Open the Templates dialog box.
  2. Click Import Templates.
  3. The Select Category dialog box appears.
  4. Select an existing category or create a new category.
  5. Browse for the downloaded template.
  6. Select the template file.
  7. Click Open.
  8. The selected template is added to the list.
⭐ EXAM POINT

Import Templates is used to add a downloaded template to the Templates list.

18. Editing a Template

Steps

  1. Select: File → Templates → Manage Templates
  2. Right-click the template that needs editing.
  3. Select Edit.
  4. Make the desired changes.
  5. Save the template.
🧠 Remember:

Edit Template → Manage Templates → Right-click → Edit

19. Setting a Custom Default Template

Writer provides a blank document as the default template. However, any template can be set as the default template.

Steps

  1. Open the Templates dialog box.
  2. Right-click the template to be made default.
  3. Select Set as Default.

After setting a template as default, new text documents use the selected default template.

20. Moving a Template

Templates can be organised by moving them between categories/folders within the Templates dialog.

⭐ EXAM FOCUS

Remember the purpose of template management: organising and reusing templates efficiently.

21. Track Changes

What is Track Changes?

Track Changes is a feature used when a document is reviewed or edited by multiple users.

Instead of permanently changing the original document, Writer keeps a record of the changes made.

The original author can later accept or reject the recorded changes.

The feature also allows reviewers to add comments.

⭐ VERY IMPORTANT

Track Changes → Record + Review + Accept/Reject + Comments

22. Track Changes Toolbar

Displaying the Toolbar

View → Toolbars → Track Changes

Important Buttons

Button Purpose
View Track Changes Displays changes made by different users.
Record Track Changes Turns on Track Changes so editing is recorded.
Previous / Next Track Changes Moves between recorded changes.
Accept / Accept All Accepts one or all recorded changes.
Reject / Reject All Rejects one or all recorded changes.
Manage Track Changes Displays detailed information about changes.
Insert Comment Adds a comment to the document.
⭐ DIRECT EXAM POINT

The Track Changes toolbar contains tools for viewing, recording, navigating, accepting, rejecting, managing changes and inserting comments.

23. Preparing a Document for Review

Purpose

Before sharing a document with reviewers, the original author should ensure that changes will be recorded.

Starting the Recording

Select: Edit → Track Changes → Record

Alternatively, click the Record button on the Track Changes toolbar.

Protecting Track Changes

The document can be protected with a password so that another user cannot disable Track Changes without entering the password.

Steps

  1. Select: Edit → Track Changes → Protect
  2. Enter the password.
  3. Confirm the password.
  4. Click OK.
24. Recording Changes

Starting Track Changes

Select: Edit → Track Changes → Record

Shortcut key to start recording changes: Ctrl + Shift + C

How Changes Appear?

  • Added characters are displayed in a different colour.
  • Deleted characters are displayed using strike-through style.
  • A tooltip can display details about the change.

Change Details

The tooltip can provide information such as:

  • Author
  • Change made
  • Date
  • Time
⭐ MUST REMEMBER

Ctrl + Shift + C → Start recording changes

25. Accepting and Rejecting Changes

Accepting a Change

The original author can accept a recorded change.

Rejecting a Change

The original author can reject a recorded change.

Important Options

Option Purpose
Accept Track Change Accepts the selected change.
Reject Track Change Rejects the selected change.
Accept All Tracked Changes Accepts all changes.
Reject All Tracked Changes Rejects all changes.
Previous Track Changes Moves to previous change.
Next Track Changes Moves to next change.
Manage Track Changes Displays detailed list of changes along with author and date/time information.
26. Adding Comments

Comments can be added while reviewing a document.

Steps

  1. Place the cursor at the location where the comment is required.
  2. Click Insert Comment on the Track Changes toolbar.
  3. A comment box appears on the right side.
  4. Type the comment.
  5. Click elsewhere on the document.
🧠 Important:

Comment boxes by different users can appear in different colours.

27. Deleting Comments

Comments can be deleted individually, by author, or all together.

Available Options

  • Delete current comment
  • Delete all comments by a particular author
  • Delete all comments
⭐ EXAM POINT

The comment menu provides options for deleting the current comment, comments of a particular author, or all comments.

28. Comparing Documents

Writer allows comparison between an original document and an edited/reviewed document.

Steps

  1. Open the edited document.
  2. Select: Edit → Track Changes → Compare Documents
  3. The Compare To dialog box appears.
  4. Browse and select the original document.
  5. The Manage Changes dialog box appears.
  6. Accept or reject the desired changes.
  7. Close the dialog box.
  8. Save the edited document.
⭐ EXAM MEMORY

Compare Documents is used to compare the original document with the reviewed/edited document.
