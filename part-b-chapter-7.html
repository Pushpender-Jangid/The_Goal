Share and Review a Spreadsheet

This chapter explains how a spreadsheet can be shared for collaborative editing and how changes can be recorded, reviewed, accepted, rejected, merged and compared in LibreOffice Calc.

01. Introduction

LibreOffice Calc allows a spreadsheet to be shared with more than one user at the same time.

A shared spreadsheet is the same spreadsheet that can be accessed by multiple users and allows them to make changes simultaneously.

Core Idea: Sharing avoids the trouble of maintaining multiple copies of the same spreadsheet edited by different users.

Benefits of Sharing

  • Multiple users can work on the same spreadsheet.
  • Users can make changes collaboratively.
  • Users can view the changes made by others.
  • It avoids maintaining multiple copies.
02. Sharing a Spreadsheet

Steps to Share a Spreadsheet

  1. Open a new spreadsheet and save it with a suitable name.
  2. Select Tools → Share Spreadsheet from the main menu bar.
  3. The Share Document dialog window opens.
  4. Select the checkbox “Share this spreadsheet with other users”.
  5. Click OK.
  6. A confirmation dialog appears asking to save the spreadsheet to activate shared mode.
  7. Click Yes to continue.
  8. After saving, the title bar displays (shared) along with the spreadsheet name.
Tools → Share Spreadsheet
⭐ EXAM POINT

The checkbox used to enable sharing is: “Share this spreadsheet with other users”.

03. Shared Mode

Once sharing is activated and the spreadsheet is saved, the word (shared) appears in the title bar along with the file name.

Spreadsheet Name + (shared)

Important Point

The shared mode allows multiple users to access and edit the spreadsheet at the same time.

04. Opening a Shared Spreadsheet

When a shared spreadsheet is opened, LibreOffice Calc displays a message informing the user that the spreadsheet is in shared mode.

Some features are not available when the spreadsheet is opened in shared mode.

Features Mentioned as Unavailable

  • Undo
  • Redo
  • Repeat
  • Paste
  • Links to External Files
  • ImageMap
  • Object
⭐ TRUE / FALSE TRAP

Some features become unavailable when a spreadsheet is in shared mode. TRUE

05. Saving a Shared Spreadsheet

After making changes in a shared spreadsheet, the spreadsheet should be saved before closing.

When Changes Do Not Conflict

If two or more users are working at the same time and their changes do not conflict, the spreadsheet can be updated with the changes saved by other users.

When Changes Conflict

If there is a conflict between changes, a Resolve Conflict dialog window appears.

  • No other user can save the shared spreadsheet while the conflict is being resolved.
  • If another user is trying to save and resolve conflicts, the file is locked.
🧠 Remember:

Conflict → Resolve Conflict dialog → File may be locked

06. Recording Changes

The Recording Changes feature of LibreOffice Calc records changes made by one or other users in the spreadsheet.

VERY IMPORTANT: When Recording Changes is enabled, the spreadsheet's shared feature is turned off.

First Step

Before enabling Record Changes, the spreadsheet must first be taken out of shared mode.

Disabling Shared Mode

  1. Open the shared spreadsheet.
  2. Select Tools → Share Spreadsheet.
  3. Remove the check mark from “Share this spreadsheet with other users”.
  4. Click OK.
  5. A confirmation dialog appears.
  6. Click Yes to continue.
  7. The word (shared) disappears from the title bar.
07. Turning ON Record Changes

Once shared mode has been disabled, the Track Changes → Record option becomes available.

Edit → Track Changes → Record

What Happens After Recording is ON?

When a change is made in the spreadsheet, Calc records the change.

The chapter's example changes the name Sia to Sita in cell B5.

The border colour of the cell in which data has been changed becomes RED.

When the cursor is moved to the changed cell, information about the recorded change is displayed.

08. Stopping Record Changes

To stop recording changes, select the Record option again.

Edit → Track Changes → Record

Alternatively, the Record button can be used from the appropriate toolbar.

⭐ EXAM FILL-IN

Recording changes is performed through Edit → Track Changes → Record.

09. Adding Comments

In Calc, comments can be added automatically as well as manually by the author or reviewer.

Adding a Comment using Track Changes

  1. Select Edit → Track Changes → Comment.
  2. The Add Comment window opens.
  3. Enter the required comment.
  4. The comment can then be viewed from the relevant cell.
Edit → Track Changes → Comment

Adding a Comment to a Cell

  1. Select the cell where the comment is required.
  2. Select Insert → Comment.
  3. A comment box appears.
  4. Enter the required note or suggestion.
Insert → Comment

Comments added through Insert → Comment are described in the chapter as notes or suggestions.

10. Viewing, Editing and Deleting Comments

After a comment is inserted, it can be displayed, edited or deleted.

Edit Comment

Right-click the cell containing the comment and select Edit Comment.

Delete Comment

Right-click the cell and select Delete Comment.

Show Comment

Right-click the cell and select Show Comment.

Hide Comment

When the comment is already being displayed, the option changes to Hide Comment.

Option Purpose
Edit Comment Modify the existing comment.
Delete Comment Remove the comment.
Show Comment Display the comment.
Hide Comment Hide the displayed comment.
11. Formatting a Comment

The comment box can be formatted similar to cell contents.

Formatting Options

  • Background colour
  • Border style
  • Transparency
  • Font
  • Font effects
  • Alignment
  • Borders
  • Background
  • Cell Protection

Basic Procedure

  1. Right-click the cell containing the comment.
  2. Select Format Cell.
  3. The Format Cells dialog box opens.
  4. Apply the required formatting.
  5. Click OK.
⭐ EXAM POINT

The comment box can be formatted just like formatting the cell contents.

12. Reviewing Changes

After all team members have edited the spreadsheet, the changes can be reviewed before preparing the final spreadsheet.

Showing Changes

Edit → Track Changes → Show

This opens the Show Changes dialog window.

The Show Changes dialog is used to decide which changes should be displayed while reviewing the spreadsheet.

Managing Changes

Edit → Track Changes → Manage

The Manage Changes dialog window is used to accept or reject changes.

13. Accepting and Rejecting Changes

The changes made by team members can be reviewed and then accepted or rejected.

Action Purpose
Accept Accept the selected change.
Reject Reject the selected change.
Accept All Accept all recorded changes.
Reject All Reject all recorded changes.

The original/owner user reviews the recorded changes and decides which changes should be accepted or rejected.

14. Merging Two Spreadsheets

If the same spreadsheet has been reviewed by different team members and different versions are available, the spreadsheets can be merged.

Merge Document

Edit → Track Changes → Merge Document

Steps to Merge

  1. Open the original spreadsheet.
  2. Select Edit → Track Changes → Merge Document.
  3. The Merge With dialog window opens.
  4. Select the second spreadsheet file.
  5. Click Open.
  6. The Manage Changes dialog window opens.
  7. Review and accept/reject the changes as required.
⭐ DIFFERENCE TO REMEMBER

Merge Document is used when two versions of a spreadsheet need to be merged.

15. Comparing Two Spreadsheets

Instead of merging two spreadsheets, Calc also allows two spreadsheets to be compared.

Compare Document

Edit → Track Changes → Compare Document

Steps to Compare

  1. Open the first spreadsheet.
  2. Select Edit → Track Changes → Compare Document.
  3. The Compare to dialog window opens.
  4. Select the spreadsheet that needs to be compared.
  5. Click Open.
  6. The Manage Changes dialog window opens.
  7. Accept or reject the required changes.
  8. Click Close when finished.
16. Merge vs Compare
Merge Document Compare Document
Used to combine changes from another version of the spreadsheet. Used to compare two spreadsheet documents.
Uses Merge Document. Uses Compare Document.
The changes can then be managed through Manage Changes. The differences/changes can be reviewed through Manage Changes.
🧠 Easy Trick:

MERGE = Combine
COMPARE = Check differences

20. 🎯 Exam-Oriented Differences

Sharing vs Recording Changes

Sharing Recording Changes
Allows multiple users to edit the spreadsheet simultaneously. Records changes made by users.
Spreadsheet remains in shared mode. Shared mode is turned off.

Comment vs Track Changes

Comment Track Changes
Adds notes or suggestions to a cell. Records modifications made to spreadsheet data.
Can be edited, deleted, shown or hidden. Recorded changes can be reviewed and accepted/rejected.
